# Reviewer-Optimized Version (Short)

I’m already building in **solana.new using Claude/Codex** as my daily workflow, and this grant directly increases how fast I can ship Lyra Record.

**Lyra Record** is a Solana verification API for agents and apps. It simulates transactions, tracks confirmation/execution state, parses the final on-chain result, and returns a verifiable receipt developers can reuse.

Why it matters: most Solana apps can trigger actions, but few expose a clean proof layer that ties together intent, execution, and outcome.

My agentic workflow is execution-focused: I split the product into clear modules (simulation, tracking, receipts, webhooks, dashboard), then use Claude/Codex for architecture planning, scaffolding, rapid implementation loops, and edge-case review.
